## 🚀 Experiência e projetos em destaque

### 🤖 Plataforma de Automações — IEL/SC
Desenvolvimento e evolução de uma plataforma corporativa para centralizar a solicitação, execução e acompanhamento de automações, reduzindo tarefas manuais e aumentando rastreabilidade, governança e escalabilidade.

A arquitetura combina **FastAPI, PostgreSQL, workers especializados, React/TypeScript, Google Apps Script, Docker e integrações com sistemas externos**, além de automações de navegador com **Playwright/Selenium** e recursos de **IA aplicada a processos e documentos**.

**Foco:** engenharia de software, automação, backend, integração de sistemas, IA aplicada, arquitetura e melhoria contínua.

### 📊 Monitoramento inteligente do RabbitMQ com n8n + RAG — TCC
Projeto desenvolvido para monitorar filas de erro do RabbitMQ, consolidar eventos e sugerir soluções por meio de uma base de conhecimento semântica.

A solução combinou **RabbitMQ, n8n, Docker, Azure, PostgreSQL/Supabase, embeddings, banco vetorial, RAG, IA generativa, deduplicação de eventos e validação humana (HITL)**.
